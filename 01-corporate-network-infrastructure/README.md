# Project 01 — Corporate Network Infrastructure

## Aguilar Technologies Inc.

**Project Status:** Phase 1 — Planning and Requirements  
**Environment:** Cisco Packet Tracer  
**Project Type:** Corporate Network Design and Security Simulation

## 1. Executive Summary

Aguilar Technologies Inc. is a fictional Canadian technology and distribution company employing 50 people across four departments.

The company requires a secure, scalable network infrastructure supporting office-based, hybrid, and remote employees.

This project demonstrates the planning, implementation, configuration, security, and troubleshooting of a simulated corporate network.

## 2. Business Environment

| Department | Employees | Desktop PCs | Laptops |
|---|---:|---:|---:|
| Administration & Finance | 10 | 6 | 4 |
| Sales & Customer Service | 15 | 5 | 10 |
| Warehouse & Operations | 20 | 12 | 8 |
| IT & Cybersecurity | 5 | 2 | 3 |
| **Total** | **50** | **25** | **25** |

The company supports a mixed workforce with desktop workstations, office laptops, hybrid employees, and remote workers.

## 3. Project Objectives

- Design and document a corporate network topology.
- Implement structured IP addressing and subnetting.
- Configure routers, switches, and wireless access.
- Segment departmental traffic using VLANs.
- Configure DHCP and network services.
- Implement inter-VLAN routing and access control lists.
- Design secure connectivity for remote employees.
- Verify connectivity, security policies, and network performance.
- Document configurations, troubleshooting procedures, and test results.

## 4. Planned Infrastructure

**Network Infrastructure**
- Routers and managed switches
- Wireless access points
- Departmental VLANs
- Corporate and guest wireless networks
- Network security controls

**Systems and Services**
- Windows Server and Active Directory
- DNS and DHCP
- Centralized file services
- Remote access and VPN
- Security monitoring and logging

Some services may be implemented in separate virtual machine labs rather than Packet Tracer.
